%<цель и задачи; можно вводное слово к работе>

Цель работы -- сравнить алгоритмы умножения матриц.\\

Задачи, необходимые для достижения поставленной цели:
\begin{enumerate}
	\item описать алгоритмы умножения матриц;
	\item ввести модель вычислений и оценить трудоёмкость каждого алгоритма в введённой модели;
	\item реализовать алгоритмы;
	\item описать архитектуру ЭВМ и выполнить замеры процессорного времени для лучшего и худшего случаев;
	\item проверить соответствие теоретической оценки полученным значениям;
	\item провести сравнительный анализ реализаций по трудоёмкости.
\end{enumerate}
