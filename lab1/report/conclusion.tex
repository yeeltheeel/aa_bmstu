В ходе работы мной были описаны алгоритмы умножения матриц, введена модель вычислений и с её помощью была вычислена трудоёмкость каждого из алгоритмов. Также были написаны реализации алгоритмов и выполнены замеры процессорного времени для лучшего и худшего случаев для каждой из реализаций.

Рассчитанная ранее теоретическая оценка трудоёмкости алгоритмов соответствует полученным на практике значениям. Реализация с наименьшим значением трудоёмкости -- реализация алгоритма Винограда с оптимизацией.

Таким образом, все задачи были выполнены, а поставленная цель достигнута.
